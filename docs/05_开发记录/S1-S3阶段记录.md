## S1 基础设施

### 目标
搭建项目骨架与基础设施，为后续所有业务模块提供统一的技术底座。

### 完成功能
- 数据库设计（8张核心表：user/exam/question/exam_record/answer_record/ai_report/grading_record/question_score_rule）
- ORM模型（SQLAlchemy 2.0）
- 数据库迁移（Alembic）
- 统一异常处理（NotFoundException / BusinessException / ValidationException / ForbiddenException / UnauthorizedException）
- 统一响应格式（ApiResponse / success / error / created）
- 日志体系（get_logger，禁止 print）

### 修改文件
- `backend/app/models/*`
- `backend/app/exceptions/*`
- `backend/app/schemas/*`
- `backend/app/db/*`

### 技术方案
采用 FastAPI + SQLAlchemy 2.0 + Alembic 架构，建立分层的后端工程结构。使用工厂模式创建数据库会话，通过 BaseException 继承体系实现全局异常捕获，确保 API 层返回一致的 JSON 响应格式。日志模块基于 Python logging 封装，统一入口避免散落在业务代码中的 print 语句。

### 测试结果
所有基础设施模块已通过单元测试，数据库迁移脚本可正常执行，异常处理和响应格式在典型场景下验证通过。

### 遗留问题
暂无明显遗留问题。

### 当前状态
✅ 已完成

## S2 考试资源管理

### 目标
实现 HR 后台考试管理功能，支持考试与题目的创建、编辑、删除和导入。

### 完成功能
- 用户认证（JWT 注册 / 登录 / 登出）
- 权限保护（HR 端点鉴权）
- 考试 CRUD（创建 / 编辑 / 删除 / 列表 / 详情）
- 题目管理（创建 / 删除 / 列表）
- JSON 导入（multipart/form-data）
- HR 前端页面（ExamList / ExamCreate / ExamDetail / QuestionFormDialog / QuestionTable）

### 修改文件
前后端多个文件，详见 `change-log.md`。

### 技术方案
后端使用 FastAPI JWT 实现无状态认证，通过依赖注入（Depends）实现 HR 角色校验。前端基于 Vue 3 + Element Plus 构建管理后台界面，使用 Pinia 维护用户状态。文件上传使用 FastAPI 的 UploadFile 处理 multipart/form-data 请求。

### 测试结果
认证流程正常，HR 角色权限校验通过，考试 CRUD 接口正常返回，题目 JSON 导入功能验证通过。

## S3 考试参与与评分

### 目标
实现候选人完整的考试流程，并建立自动化与 AI 辅助评分体系。

### 完成功能
- **S3.1 候选人考试后端**：考试记录创建 / 开始 / 答题 / 提交
- **S3.2 候选人考试前端**：CandidateEntry / Exam.vue / 答题 / 倒计时 / 提交
- **S3.3.1 评分基础架构**：grading_record + question_score_rule
- **S3.3.2 客观题自动评分**：ObjectiveGrader
- **S3.3.3 评分结果查询**：HR 端列表 + 详情
- **S3.3.4 AI-Service 调用链路**：Backend → AI-Service → Agent → LLM
- **S3.3.5 主观题 AI 评分集成**：ScoringAgent + AI 评分结果存储
- **S3.3.6 AI 考试分析报告**：ReportAgent + AI 报告生成
- **S3.4 日志体系完善**

### 修改文件
前后端多个文件，涉及考试记录、评分、AI 服务调用等模块。

### 技术方案
候选人考试流程采用"记录驱动"模式，通过 exam_record 状态机控制考试生命周期。客观题使用规则引擎（ObjectiveGrader）实现即时评分；主观题通过 AI-Service 微服务调用 LLM 完成评分。评分结果写入 grading_record 表，支持多次评分记录。AI 报告由 ReportAgent 生成，存储于 ai_report 表。

### 测试结果
候选人可正常进入考试、答题、倒计时、提交。客观题即时评分正确。AI 评分链路从 Backend 到 AI-Service 到 LLM 调用正常。评分结果和报告可在 HR 端正确查看。

### 遗留问题
暂无明显遗留问题。

### 当前状态
✅ 已完成
