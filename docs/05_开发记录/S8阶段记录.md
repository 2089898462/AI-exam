## S8.1 监考基础能力

### 目标
实现监考基础检测能力，监控候选人考试过程中的页面可见性变化。

### 完成功能
- useMonitor.js 基础框架
- visibilitychange / blur / focus / pagehide / pageshow 监听
- leave / return 事件记录
- leaveCount / totalHiddenDuration 统计

### 修改文件
新增 `frontend/src/composables/useMonitor.js` 监考组合式函数。

### 技术方案
封装 Vue 3 Composable（useMonitor.js），通过 `visibilitychange`、`blur`、`focus`、`pagehide`、`pageshow` 五类浏览器事件监听页面可见性状态。当候选人离开考试页面时记录 leave 事件，返回时记录 return 事件。维护 leaveCount（离开次数）和 totalHiddenDuration（累计隐藏时长）两个核心统计指标，通过 localStorage 持久化防止刷新丢失。

### 测试结果
离开 / 返回事件正确触发，次数和时长统计准确，页面刷新后数据可恢复。

### 遗留问题

## S8.3 事件体系增强

### 目标
增强监考事件检测能力，提升对异常行为的识别精度。

### 完成功能
- **S8.3.1 环境采集**：设备 / 屏幕 / 网络 / 浏览器
- **S8.3.2 异常标签计算**：rapid_leave_return / long_leave / frequent_leave / network_related
- **S8.3.3-a 移动端事件检测增强**：iOS Safari pagehide / pageshow 兼容
- **S8.3.3-b 事件合并机制重构**：scheduleAction、100ms 合并窗口、action 抢占解决 leave / return 丢失
- **S8.3.3-c 去重机制优化**：500ms DEDUP_WINDOW
- **S8.3.3-d 移动端切屏检测修复**：MERGE_WINDOW 300ms → 100ms、action 抢占

### 修改文件
useMonitor.js 核心逻辑、事件处理子模块、异常标签计算模块。

### 技术方案
**环境采集**：通过浏览器 API 获取设备类型、屏幕分辨率、网络状态（Online/Offline）、浏览器信息。
**异常标签**：基于事件时间线计算四类异常标签——rapid_leave_return（快速往返，<3 秒）、long_leave（长时间离开，>30 秒）、frequent_leave（高频离开，>5 次）、network_related（网络切换关联离开）。
**iOS Safari 兼容**：针对 iOS Safari 特殊处理 pagehide / pageshow 事件，避免后台挂起导致的事件丢失。
**事件合并机制**：引入 scheduleAction 调度器，使用 100ms 合并窗口将短时间内的多个事件合并处理，通过 action 抢占机制解决 leave / return 事件丢失问题。
**去重机制**：设置 500ms DEDUP_WINDOW 防止同一事件被重复记录。
**移动端修复**：将 MERGE_WINDOW 从 300ms 优化为 100ms，配合 action 抢占机制确保移动端切屏事件不丢失。

### 测试结果
环境采集数据准确，异常标签计算逻辑正确。iOS Safari 和移动端事件检测修复有效。事件合并和去重机制稳定运行。

### 遗留问题
暂无明显遗留问题。

### 当前状态
✅ 已完成

## S8.4 状态恢复与异常分析

### 目标
实现监考闭环与异常分析能力，提供完整的监考后处理与恢复机制。

### 完成功能
- **S8.4.1 后端异常行为分析**：快速往返 / 长时间离开 / 高频离开 / 网络关联 / 刷新尝试检测
- **S8.4.2 异常行为检测增强**：行为标签 / 风险原因 / 最大密度计算
- **S8.4.3 HR 监考分析增强**：风险摘要卡片 / 审核建议 / 异常标签
- **S8.4.3-c 移动端监考详情适配**：垂直布局 / 异常时间线 / 触摸目标 ≥44px
- **S8.4.4 考试状态恢复**：服务器时间锚点倒计时 / sessionStorage 持久化 / leave_recovered 补偿 / 提交后清理
- **S8.4.5 监考异常展示优化**：事件中文映射 / 详情说明 / 风险摘要 / 审核建议
- **S8.4.6 监考闭环回归验证与稳定性优化**：max_single_duration 修复 / 日志开关 / 全链路回归 18/18 通过
- **S8.4.7 考试开始前诚信警示弹窗**：不可关闭威慑弹窗 / 移动端适配

### 修改文件
后端监考分析服务、HR 前端监考详情页面、useMonitor.js 状态恢复模块、诚信弹窗组件、异常行为检测模块。

### 技术方案
**后端异常分析**：接收前端上报的监考事件，分析快速往返（<3s）、长时间离开（>30s）、高频离开（>5次）、网络关联离开、刷新尝试等异常行为。计算行为标签和风险原因。
**异常检测增强**：引入最大密度计算（时间窗口内事件密度）识别群体性异常模式。
**HR 监考分析增强**：前端增加风险摘要卡片，展示风险等级和审核建议。异常标签以彩色徽章形式展示。
**移动端适配**：监考详情页采用垂直布局，异常时间线优化触摸交互，所有触摸目标 ≥44px 符合移动端设计规范。
**考试状态恢复**：倒计时采用服务器时间锚点防止本地时间篡改。考试状态持久化到 sessionStorage，离开后返回可恢复倒计时。leave_recovered 机制对"已离开但已返回"的状态进行补偿标记。提交后自动清理所有监考数据。
**异常展示优化**：事件类型中文映射表，详情说明文案优化。
**回归验证**：修复 max_single_duration 计算 Bug，增加日志开关便于调试。18 项全链路回归测试全部通过。
**诚信警示弹窗**：考试开始前弹出不可关闭的诚信承诺弹窗，候选人必须点击"我已阅读并承诺"才能进入考试。弹窗适配移动端显示。

### 测试结果
后端异常分析逻辑正确，风险等级判定合理。HR 端监考分析展示完整，移动端适配良好。考试状态恢复在刷新、离开、返回场景下均正常工作。18/18 全链路回归测试通过。诚信弹窗在桌面端和移动端均可正常展示。

### 遗留问题
暂无明显遗留问题。

### 当前状态
✅ 全部已完成
