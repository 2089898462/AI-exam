### 修改文件

## S5.7-G Windows 一键启动脚本

### 目标
提供便捷的 Windows 环境一键启动能力。

### 完成功能
- start-system.bat / stop-system.bat
- 端口验证
- 自动打开浏览器

### 修改文件
新增 start-system.bat 和 stop-system.bat 脚本。

### 技术方案
start-system.bat 依次启动 AI-Service、Backend、Frontend 三个服务，每个服务启动后验证对应端口是否就绪。全部服务启动完成后自动打开浏览器访问前端页面。stop-system.bat 负责安全停止所有服务进程。

### 测试结果
一键启动 / 停止脚本在 Windows 环境下运行正常，三个服务可按预期启动和停止。

### 遗留问题
暂无明显遗留问题。

✅ 已完成
