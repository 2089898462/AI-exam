# 产品需求文档

## 版本 v0.1.0 (MVP)

### 功能清单

#### 1. 考试管理 (HR后台)
- [ ] 创建考试（基本信息：名称、时间、说明）
- [ ] 导入考试JSON文件
- [ ] 发布/取消发布考试
- [ ] 查看考试列表
- [ ] 查看成绩列表

#### 2. 在线考试 (考生端)
- [ ] 手机网页进入考试
- [ ] 支持题型：单选题、多选题、判断题、简答题
- [ ] 提交答案

#### 3. 自动评分
- [ ] 客观题（单选、多选、判断）：系统自动评分
- [ ] 主观题（简答）：AI评分

#### 4. AI能力分析报告
- [ ] 优势能力
- [ ] 薄弱能力
- [ ] 学习建议
