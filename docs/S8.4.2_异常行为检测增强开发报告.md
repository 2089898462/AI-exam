## 2. 新增功能说明

### 2.1 前端事件标签系统
- **功能**: 为每个监考事件（exam_leave / exam_return）增加 `tags` 字段
- **触发时机**: 事件产生时实时计算
- **支持标签**:
  - `rapid_leave_return`: 快速离开返回
  - `long_leave`: 长时间离开
  - `frequent_leave`: 高频离开
  - `network_related`: 网络相关离开

### 2.2 后端异常行为分析
- **功能**: 独立分析函数 `analyze_monitor_behavior()`
- **输入**: monitor_data（监考数据）
- **输出**: behavior_tags + risk_reason + analysis 指标
- **特点**: 纯分析，不干预考试流程

### 2.3 风险等级计算 V3
- **功能**: 增强版风险等级判定
- **新增维度**:
  - 网络异常豁免机制
  - 快速往返高频次检测
  - 集中式异常密度检测
  - 行为标签辅助判定
- **保持**: 4级风险等级（normal/low/medium/high）

### 2.4 HR 前端展示增强
- **功能**: HR 端监考信息增强展示
- **新增展示**:
  - 异常行为标签区
  - 异常行为详情表格
  - 事件标签列

## 3. 异常规则说明

### 3.1 rapid_leave_return（快速离开返回）
- **规则**: 离开后 5 秒内返回
- **判定位置**: 前端 `calculateTags('return', duration)` + 后端 `_count_rapid_trips()`
- **风险影响**:
  - 1-2次 → 不升级（保持 low 或原等级）
  - ≥3次 → 升级为 high

### 3.2 long_leave（长时间离开）
- **规则**: 单次离开 ≥ 60 秒
- **判定位置**: 前端 `calculateTags('return', duration)` + 后端 `analyze_monitor_behavior()`
- **风险影响**:
  - ≥ 300秒 → 直接 high
  - 60-300秒 → 至少 medium

### 3.3 frequent_leave（高频离开）
- **规则**: 5 分钟内离开 ≥ 3 次
- **判定位置**: 前端 `calculateTags('leave')` + 后端 `_calc_max_leave_density()`
- **风险影响**:
  - 密度 > 1次/分钟 → 至少 medium
  - 密度 0.6-1.0次/分钟 → 视累计情况

### 3.4 network_related（网络相关离开）
- **规则**: 离开发生在 network_offline 事件后 30 秒内
- **判定位置**: 前端 `calculateTags('leave')` + 后端 `_count_network_related_leaves()`
- **风险影响**:
  - 所有离开都是网络相关 → 豁免为 normal
  - 部分网络相关 → 不豁免

### 3.5 refresh_attempt（刷新尝试）
- **规则**: pageshow.persisted（bfcache 恢复）
- **判定位置**: 前端 `onPageShow(event)` + 后端 `analyze_monitor_behavior()`
- **风险影响**: 作为辅助标签，配合其他指标判定

## 4. 数据结构变化

### 4.1 events 事件结构（向前兼容）

**S8.4.1 格式**（仍然有效）:
```json
{
  "type": "exam_leave",
  "timestamp": 1700000000000,
  "duration": 3000
}
```

**S8.4.2 增强格式**（新增 tags 字段）:
```json
{
  "type": "exam_leave",
  "timestamp": 1700000000000,
  "duration": 3000,
  "tags": ["rapid_leave_return"]
}
```

### 4.2 detail_data 结构（向后兼容）

**旧数据格式**（S7.x）:
```json
{
  "events": [...]
}
```

**S8.4.1 格式**:
```json
{
  "events": [...],
  "environment": {...}
}
```

**S8.4.2 增强格式**:
```json
{
  "events": [...],
  "environment": {...},
  "analysis": {
    "behavior_tags": ["frequent_leave"],
    "risk_reason": ["离开行为集中，最大密度0.8次/分钟"],
    "max_single_duration": 300,
    "leave_frequency": 8.0,
    "rapid_trips": 1,
    "max_leave_density": 0.8,
    "network_related_leaves": 0,
    "refresh_attempts": 0,
    "total_leave_count": 4,
    "total_duration": 40
  }
}
```

**兼容性说明**: 
- 旧数据无 `analysis` 字段 → 读取时默认为空对象
- 旧事件无 `tags` 字段 → 显示时默认为空数组
- JSON 解析完全兼容，不影响旧数据读取

## 5. 风险计算变化

### 5.1 V2 → V3 规则对比

| 规则 | V2（S8.4.1） | V3（S8.4.2） |
|------|-------------|-------------|
| 无离开 | normal | normal |
| 单次≥300秒 | high | high |
| 离开占比≥20% | high | high |
| 离开次数>8 | high | high |
| **网络豁免** | ❌ 无 | ✅ 所有离开网络相关→normal |
| **快速往返≥3** | ❌ 无 | ✅ high |
| **集中密度>1次/分** | ❌ 无 | ✅ 至少 medium |
| **高频标签触发** | ❌ 无 | ✅ medium |
| **快速返回1-2次** | ❌ 无 | ✅ low |
| **长时间离开(60-300s)** | ❌ 无 | ✅ 至少 medium |
| 短时间少量离开 | low | low |

### 5.2 V3 判定流程图

```
开始
  │
  ├── leave_count == 0 ──────────────► normal
  │
  ├── 所有离开网络相关 ──────────────► normal（网络豁免）
  │
  ├── rapid_trips >= 3 ─────────────► high
  │
  ├── max_single_duration >= 300 ───► high
  │
  ├── leave_ratio >= 20% ───────────► high
  │
  ├── leave_count > 8 ──────────────► high
  │
  ├── max_density > 1次/分钟 ───────► 至少 medium
  │
  ├── frequent_leave 标签 + ≥3次 ───► medium
  │
  ├── rapid_trips 1-2次 ───────────► low
  │
  ├── long_leave 标签 ──────────────► 至少 medium
  │
  ├── max_single < 30s && ≤3次 ─────► low
  │
  └── 其他 ───────────────────────► medium
```

## 8. 已知限制

| # | 限制 | 说明 |
|---|------|------|
| 1 | 标签依赖前端上报 | 如前端未升级，后端无法生成标签 |
| 2 | 网络检测依赖浏览器 API | 部分旧浏览器不支持 Network Information API |
| 3 | 快速往返判定基于 duration | 如果 duration 为 0（进行中），不触发判定 |
| 4 | 密度计算基于时间戳 | 依赖事件 timestamp 的准确性 |
| 5 | 历史数据无分析 | S7.x 考试记录无 analysis 数据，展示为空 |
