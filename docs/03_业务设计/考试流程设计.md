## 候选人考试流程详细步骤

### 1. 入口阶段
- **页面组件**：`CandidateEntry.vue`
- **核心功能**：
  - 姓名输入验证
  - 手机号验证（格式校验）
  - 考试信息展示
  - 身份校验通过后生成唯一考试会话

### 2. 考试页面阶段
- **页面组件**：`Exam.vue`
- **核心流程**：
  1. **加载试卷**：从后端获取题目列表
  2. **倒计时**：显示考试剩余时间，时间到自动提交
  3. **监考启动**：启动防作弊监控
  4. **答题**：逐题作答，支持翻页
  5. **提交**：检查未答题目，确认提交

### 3. 状态流转

```
not_started ──→ in_progress ──→ submitted ──→ graded
   (未开始)        (进行中)       (已提交)       (已评分)
```

- **not_started**：候选人进入前的初始状态
- **in_progress**：候选人正在答题
- **submitted**：已提交，等待评分
- **graded**：评分完成，可查看结果

### 4. 自动保存机制
- 每 **30秒** 自动保存当前答案到服务器
- 支持手动保存按钮
- 网络异常时本地缓存，恢复后同步

### 5. 断点恢复
- 刷新页面或切换后台后，自动恢复：
  - 剩余考试时间
  - 已答题目及答案
  - 答题进度

## HR管理流程

### 考试管理
```
创建考试 → 编辑考试 → 发布考试 → 关闭考试
    │          │          │          │
    ▼          ▼          ▼          ▼
 填写基本   修改题目    通知候选人  截止所有
 信息/题目  或参数     开始答题    未提交考试
```

- **创建**：填写考试名称、时长、及格分、添加题目
- **编辑**：修改考试参数或题目内容（未发布前）
- **发布**：生成考试链接，开放给候选人
- **关闭**：结束考试，所有未提交的答卷强制提交

### 成绩查看
```
成绩列表 ──→ 成绩详情 ──→ 监考详情
    │           │           │
    ▼           ▼           ▼
 查看所有    查看单份      查看监考
 候选人成绩  答卷详情      行为记录
```

- **成绩列表**：展示所有候选人的成绩、是否及格
- **成绩详情**：查看单份答卷的每题得分、答案对比
- **监考详情**：查看候选人的监考行为记录（切屏次数、异常行为）

### AI报告查看
- 查看AI生成的候选人分析报告
- 包含： strengths（优势）、weaknesses（薄弱点）、learning_suggestions（学习建议）

## 异常处理

| 异常场景 | 处理方案 |
|---------|---------|
| 网络断线 | 本地缓存答案，恢复后自动同步 |
| 考试超时 | 自动提交已答题目 |
| 页面刷新 | 断点恢复，不丢失进度 |
| 重复提交 | 后端幂等处理，只评一次 |
| 身份过期 | 提示重新验证身份 |
