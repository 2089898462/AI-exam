# 【当前有效】题库管理设计

## 题型支持

本系统支持以下四种题型：

| 题型标识 | 题型名称 | 说明 |
|---------|---------|------|
| `single_choice` | 单选题 | 从多个选项中选择一个正确答案 |
| `multiple_choice` | 多选题 | 从多个选项中选择多个正确答案 |
| `true_false` | 判断题 | 判断命题的正误 |
| `short_answer` | 简答题 | 考生用文字自由作答，由AI评分 |

---

## 题目数据结构

```typescript
interface Question {
  id: string;              // 题目唯一标识
  type: QuestionType;      // 题型
  content: string;         // 题目内容/题干
  options: Option[] | null;// 选项（JSON格式，简答题为null）
  answer: string;          // 正确答案
  score: number;           // 分值
  sort_order: number;      // 排序序号
  analysis?: string;       // 题目解析（可选）
}

interface Option {
  label: string;           // 选项标签（A/B/C/D）
  content: string;         // 选项内容
}
```

### 各题型answer字段格式

| 题型 | answer格式示例 | 说明 |
|-----|---------------|------|
| 单选题 | `"B"` | 正确选项的label |
| 多选题 | `"A,C,D"` | 多个正确选项用逗号分隔 |
| 判断题 | `"true"` 或 `"false"` | 布尔值字符串 |
| 简答题 | `"参考答案内容"` | 参考答案文本 |

## 考试创建方式

### 方式一：手动创建
- **页面组件**：`ExamCreate.vue`
- **流程**：
  1. 填写基本信息（考试名称、时长、及格分）
  2. 选择/添加题目
  3. 设置题目分值
  4. 预览并保存

### 方式二：JSON导入
- **页面组件**：`ImportExamDialog.vue`
- **技术实现**：`multipart/form-data` 文件上传
- **流程**：
  1. 选择JSON文件
  2. 前端校验格式
  3. 上传至后端解析
  4. 校验题目合法性
  5. 生成考试草稿

### 方式三：模板复制
- **页面组件**：`TemplateDetail.vue`
- **流程**：
  1. 浏览模板列表
  2. 选择模板查看详情
  3. 点击「生成考试」
  4. 自动填充题目和参数
  5. 调整后发布

## JSON导入格式规范

### 顶层结构

```json
{
  "title": "新人入职考试",
  "description": "适用于所有新入职员工的基础考试",
  "duration_minutes": 30,
  "pass_score": 60,
  "questions": [
    // 题目数组
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| `title` | string | ✅ | 考试标题，最多100字 |
| `description` | string | ❌ | 考试描述 |
| `duration_minutes` | number | ✅ | 考试时长（分钟），范围5-180 |
| `pass_score` | number | ✅ | 及格分数，总分的百分比 |
| `questions` | array | ✅ | 题目数组，至少1题 |

### 完整示例

```json
{
  "title": "新人入职考试",
  "description": "适用于所有新入职员工的基础考试，涵盖公司文化、规章制度等内容。",
  "duration_minutes": 30,
  "pass_score": 60,
  "questions": [
    {
      "type": "single_choice",
      "content": "公司成立于哪一年？",
      "options": [
        {"label": "A", "content": "2015年"},
        {"label": "B", "content": "2018年"},
        {"label": "C", "content": "2020年"},
        {"label": "D", "content": "2023年"}
      ],
      "answer": "B",
      "score": 10,
      "sort_order": 1
    },
    {
      "type": "multiple_choice",
      "content": "以下哪些是公司的核心价值观？（多选）",
      "options": [
        {"label": "A", "content": "客户至上"},
        {"label": "B", "content": "诚信正直"},
        {"label": "C", "content": "追求卓越"},
        {"label": "D", "content": "团队协作"}
      ],
      "answer": "A,B,C,D",
      "score": 15,
      "sort_order": 2
    },
    {
      "type": "true_false",
      "content": "公司实行弹性工作制，员工可自由安排工作时间。",
      "options": null,
      "answer": "true",
      "score": 5,
      "sort_order": 3
    },
    {
      "type": "short_answer",
      "content": "请简述公司的使命和愿景。",
      "options": null,
      "answer": "我们致力于用技术创新赋能每一位员工，让工作更高效、更有意义。",
      "score": 20,
      "sort_order": 4
    }
  ]
}
```

### 校验规则

1. **标题不可为空**，长度不超过100字符
2. **时长范围**：5-180分钟
3. **及格分范围**：0-100（百分比）
4. **题目数量**：至少1题，最多100题
5. **单选/判断题**：必须包含`options`且至少2个选项
6. **简答题**：`options`为`null`，`answer`为参考答案文本
7. **每题分值**：正整数，总分不超过1000分
8. **排序序号**：从1开始递增，不可重复

## 模板系统

### 模板管理流程

```
┌────────────┐    保存为模板    ┌────────────┐
│ 创建考试    │ ─────────────→ │ 模板库      │
└────────────┘                └────────────┘
                                     │
                                     │ 从模板生成
                                     ▼
                               ┌────────────┐
                               │ 新考试草稿  │
                               └────────────┘
```

### 功能说明

- **创建模板**：HR可将任意考试保存为模板
- **模板字段**：模板名称、描述、题目集合、参数预设
- **从模板生成**：选择模板后快速创建新考试
- **模板分类**：按考试类型/部门分类管理
- **模板版本**：支持模板的版本迭代

### 使用场景

| 场景 | 说明 |
|-----|------|
| 周期性考试 | 如每月/每季固定考试，模板可复用 |
| 新员工入职 | 统一的入职考试模板 |
| 部门考核 | 各部门自定义考核模板 |

## 考试参与者

### 白名单模式
- 指定具体参与人员名单
- 仅名单内的员工可参加考试
- 通过手机号或工号识别身份

### 开放参加模式
- 生成公开考试链接
- 任何人持有链接均可参加
- 适合大规模考核场景

### 对比

| 特性 | 白名单模式 | 开放参加模式 |
|-----|-----------|-------------|
| 参与者 | 指定人员 | 任何人 |
| 身份验证 | 手机号+姓名验证 | 手机号+姓名验证 |
| 防代考 | 工号匹配 | 基础验证 |
| 适用场景 | 正式考核 | 培训/测评 |
