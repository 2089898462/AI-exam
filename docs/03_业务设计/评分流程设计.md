## 客观题自动评分（ObjectiveGrader）

### 评分逻辑

#### 单选题
```typescript
function gradeSingleChoice(userAnswer: string, correctAnswer: string): GradingResult {
  const isCorrect = userAnswer.trim().toUpperCase() === correctAnswer.trim().toUpperCase();
  return {
    isCorrect,
    score: isCorrect ? question.score : 0
  };
}
```

- **比对方式**：将用户答案与正确答案的`answer`字符串直接比对
- **处理**：统一转大写后比对，忽略空格

#### 多选题
```typescript
function gradeMultipleChoice(userAnswer: string, correctAnswer: string): GradingResult {
  const userSet = parseAndSort(userAnswer);      // 逗号分隔 → 排序 → 集合
  const correctSet = parseAndSort(correctAnswer); // 逗号分隔 → 排序 → 集合
  const isCorrect = arraysEqual(userSet, correctSet);
  return {
    isCorrect,
    score: isCorrect ? question.score : 0
  };
}
```

- **比对方式**：将双方答案按逗号分隔后排序，再进行数组比对
- **要求**：必须完全一致，多选/少选/错选均不得分

#### 判断题
```typescript
function gradeTrueFalse(userAnswer: string, correctAnswer: string): GradingResult {
  const isCorrect = userAnswer.toLowerCase() === correctAnswer.toLowerCase();
  return {
    isCorrect,
    score: isCorrect ? question.score : 0
  };
}
```

- **比对方式**：`true` / `false` 字符串直接比对
- **处理**：统一转小写后比对

### 输出结构

```typescript
interface GradingResult {
  isCorrect: boolean;  // 是否正确
  score: number;       // 得分
}
```

## AI主观题评分（ScoringAgent）

### 评分流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  构建评分输入  │ ──→ │  调用AI服务   │ ──→ │  解析AI返回   │ ──→ │  结构化输出   │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
                            │
                     POST /ai-scoring/scoring
                            │
                            ▼
                     ┌──────────────┐
                     │  AI服务处理   │
                     └──────────────┘
```

### 输入参数

```typescript
interface AIScoringInput {
  question: {
    type: string;           // 题型
    content: string;       // 题目内容
    score: number;          // 题目满分
  };
  standard_answer: string;  // 标准答案
  scoring_rules: string;    // 评分规则/要点
  user_answer: string;      // 用户作答
}
```

### 输出结构

```typescript
interface AIScoringOutput {
  score: number;                    // 得分（0至满分）
  reason: string;                   // 评分理由
  missing_points: string[];         // 缺失的要点
  confidence: number;                // AI置信度（0-1）
  model_used: string;               // 使用的模型名称
  prompt_version: string;           // 使用的Prompt版本
}
```

### 容错机制

| 异常场景 | 降级策略 |
|---------|---------|
| AI服务超时（>30s） | 标记为"待人工批改" |
| AI服务不可用 | 标记为"待人工批改" |
| 返回格式异常 | 重试1次后仍失败则人工批改 |
| 置信度低于0.6 | 提示HR复核 |

## 混合评分汇总

### 评分逻辑

```
total_score = Σ(客观题得分) + Σ(主观题AI评分得分)
```

### 执行步骤

1. **遍历所有题目**
   - 客观题 → 调用 `ObjectiveGrader` 评分
   - 主观题 → 调用 `ScoringAgent` 评分
2. **汇总得分**
   - 累加所有已评分题目的得分
3. **生成报告**
   - 调用AI生成分析报告
4. **判断及格**
   - `total_score >= pass_score` → 及格
   - `total_score < pass_score` → 不及格

## 评分状态机

```
  ┌──────────┐    开始评分    ┌──────────┐    完成    ┌───────────┐
  │  pending  │ ───────────→ │ grading  │ ────────→ │ completed │
  │ (待评分)  │              │ (评分中) │          │ (已完成)  │
  └──────────┘              └──────────┘          └───────────┘
                                   │
                                   │ 评分失败
                                   ▼
                              ┌──────────┐
                              │  failed  │
                              │ (失败)   │
                              └──────────┘
```

- **pending**：答卷提交后等待评分
- **grading**：正在执行评分流程
- **completed**：评分完成，结果可用
- **failed**：评分失败，需人工介入

```
┌─────────┐    ┌─────────┐    ┌──────────────┐    ┌──────────┐    ┌─────────┐
│ Backend │ ──→ │AI Service│ ──→ │ ScoringAgent  │ ──→ │LLM Client│ ──→ │DeepSeek │
└─────────┘    └─────────┘    └──────────────┘    └──────────┘    └─────────┘
                  │                                                    │
                  │  HTTP/JSON                                         │ API调用
                  ▼                                                    ▼
           ┌──────────────────────────────────────────────────────────────┐
           │                    结构化JSON返回                              │
           │  { score, reason, missing_points, confidence, ... }          │
           └──────────────────────────────────────────────────────────────┘
```

### 链路说明

| 层级 | 组件 | 职责 |
|-----|------|------|
| 1 | Backend | 接收评分请求，调度评分流程 |
| 2 | AI Service | 评分服务入口，路由到对应Agent |
| 3 | ScoringAgent | 构建Prompt，解析AI返回 |
| 4 | LLM Client | 封装LLM API调用 |
| 5 | DeepSeek | 大语言模型服务 |

## 分数计算公式

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   total_score                                       │
│     = Σ(客观题各题得分)                              │
│     + Σ(主观题AI评分得分)                            │
│                                                     │
│   pass判定: total_score >= pass_score ? "及格" : "不及格" │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 注意事项

- 客观题按满分评分，答错得0分
- 主观题AI评分按实际表现给分，范围0至满分
- 多选题必须完全正确才能得分
- AI评分的置信度低于0.6时需要HR复核
