# 项目背景

## 项目名称
企业AI智能考试与能力评估系统

## 使用场景
公司人事部门用于：
1. 招聘面试阶段纸面考试替代
2. 员工试用期培训考试
3. 员工学习成果评估

## 当前痛点
- HR人工批改考试效率低
- 主观题评分标准不统一
- 员工能力不足无法快速发现

## 项目目标
开发一个网页系统：
- HR后台管理考试
- 候选人/员工手机端参加考试
- 系统自动评分
- AI生成能力分析报告

## 技术路线
- 前端：Vue3 + Vite + Element Plus
- 后端：Python + FastAPI + SQLAlchemy
- 数据库：MySQL 8
- AI服务：独立Python服务
- 部署：Docker
