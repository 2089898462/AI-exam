- **项目目标**：企业内部 AI 智能考试与测评系统
- **使用人员**：管理员、HR（核心）、员工

# 2. 当前技术架构

| 服务 | 端口 | 技术栈 |
|------|------|--------|
| Frontend | 3000 | Vue3 + Vite + Element Plus |
| Backend | 8000 | FastAPI + SQLAlchemy 2.0 |
| AI-Service | 8001 | FastAPI + httpx + DeepSeek |
| Database | 3306 | MySQL 8.0 |
