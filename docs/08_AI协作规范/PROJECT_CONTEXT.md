# 1. 项目名称

**AI考试系统（企业内部版）**

# 2. 项目目标

构建企业内部 AI 智能考试与测评系统，为人事部门提供一站式考试管理解决方案。

## 功能范围
- 考试创建 / 发布 / 管理
- 员工在线考试
- 客观题自动评分
- AI 主观题评分
- AI 考试分析报告
- HR 成绩管理
- 监考系统（事件检测+持久化+异常分析+HR展示）
- 诚信警示弹窗

## 业务价值
- 替代人工批改，效率提升 80%+
- AI 主观题评分，标准统一
- AI 考试分析报告，帮助 HR 快速了解考试情况

# 3. 核心设计

## 设计原则
1. **固定试卷模式**：不开发随机组卷
2. **员工嵌入式身份**：姓名+手机+考试码，无需注册
3. **HR 统一管理**：人事部门管理所有考试
4. **AI 服务独立部署**：端口 8001，解耦业务与 AI
5. **聚焦核心流程**：考试流程完整可用

## 技术决策（已确定）
| # | 决策 | 说明 |
|---|------|------|
| 1 | 固定试卷模式 | 首期聚焦核心流程 |
| 2 | 员工嵌入式身份 | 无需注册账号 |
| 3 | AI 服务独立部署 | 解耦业务与 AI |
| 4 | Prompt 与代码分离 | YAML 版本化管理 |
| 5 | Alembic 管理数据库 | 版本化迁移 |
| 6 | 密码 bcrypt 哈希 | 安全行业标准 |
| 7 | API 统一 /api/v1 前缀 | 支持版本扩展 |
| 8 | Service 层封装业务逻辑 | API 不直接操作数据库 |

# 4. 技术架构

## 整体架构
```
Frontend (Vue3:3000) → Backend (FastAPI:8000) → MySQL 8.0
                              ↓ HTTP
                         AI Service (FastAPI:8001)
```

## 服务划分
| 服务 | 端口 | 技术栈 | 职责 |
|------|------|--------|------|
| Frontend | 3000 | Vue3 + Vite + Element Plus | 用户界面 |
| Backend | 8000 | FastAPI + SQLAlchemy | 业务 API |
| AI Service | 8001 | FastAPI + httpx | AI 评分、报告 |
| MySQL | 3306 | MySQL 8.0 | 数据存储 |
