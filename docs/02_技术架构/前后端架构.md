## 1. 后端分层架构

### 1.1 分层架构图

```
┌─────────────────────────────────────────────────────────┐
│                        API 层 (Router)                    │
│   app/api/v1/endpoints/                                   │
│   - 路由注册、参数校验、权限控制、响应封装                  │
└─────────────────────────┬───────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                       Schema 层                           │
│   app/schemas/                                            │
│   - Pydantic 模型，请求/响应数据结构校验                    │
└─────────────────────────┬───────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                       Service 层                          │
│   app/services/（20+ Service）                            │
│   - 业务逻辑、事务编排、调用 AI 服务                       │
└─────────────────────────┬───────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                       Model 层                            │
│   app/models/（16+ ORM 模型）                             │
│   - SQLAlchemy 声明式 ORM 实体定义                         │
└─────────────────────────┬───────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                      Database (MySQL)                     │
└─────────────────────────────────────────────────────────┘
```

### 1.2 后端目录结构

| 目录 | 职责说明 |
|------|---------|
| `app/api/v1/endpoints/` | 路由层：参数校验 + 调用 Service + 返回响应（REST API 入口） |
| `app/schemas/` | Pydantic 数据校验层，定义请求/响应结构 |
| `app/services/` | 业务逻辑层（20+ Service），核心业务编排 |
| `app/models/` | ORM 模型（16+ 模型），数据库实体映射 |
| `app/core/` | 核心配置：config、logger、middleware、security、permissions |
| `app/db/` | 数据库连接管理：Session、Base、engine |
| `app/exceptions/` | 统一异常处理，错误码与响应规范 |
| `app/utils/` | 工具函数：password、response 等通用工具 |

## 2. 前端分层架构

### 2.1 前端分层架构图

```
┌──────────────────────────────────────────┐
│              页面层 (Views)                │
│   src/views/                              │
│   - Exam.vue / Login.vue / 管理后台页面    │
└─────────────────────────┬────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────┐
│            组件层 (Components)             │
│   src/components/exam/                    │
│   - QuestionCard / ChoiceQuestion 等      │
└─────────────────────────┬────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────┐
│           Store 层 (Pinia)                │
│   src/stores/                             │
│   - exam.js / user.js 等全局状态           │
└─────────────────────────┬────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────┐
│          API 封装层 (API)                 │
│   src/api/                                │
│   - auth / exam / examRecord / grading…  │
└──────────────────────────────────────────┘
```

### 2.2 前端目录结构

| 目录 | 职责说明 |
|------|---------|
| `src/views/` | 页面：admin（管理后台）、candidate（候选人）、exam（考试）、login（登录） |
| `src/components/exam/` | 考试相关组件：QuestionCard、ChoiceQuestion、TextQuestion、ImportExamDialog 等 |
| `src/stores/` | Pinia Store：exam.js、user.js 等全局状态管理 |
| `src/api/` | API 封装：auth、exam、examRecord、gradingResult、question、report、template、participant |
| `src/hooks/` | 组合式函数：useMonitor、useAutoSave |
| `src/layouts/` | 布局组件：AdminLayout、ExamLayout |
| `src/router/` | 路由守卫与路由配置 |
| `src/utils/` | 工具函数：request、auth |

## 3. 关键页面说明

### 3.1 Exam.vue
考试主页面，包含：
- 倒计时组件
- 监考检测集成
- 答题卡（Answer Sheet）
- 交卷/提交逻辑

### 3.2 GradingResultDetail.vue
HR 监考详情页，提供：
- 风险摘要（Risk Summary）
- 事件时间线（Event Timeline）
- AI 审核建议

### 3.3 GradingResultList.vue
HR 成绩列表页，展示候选人成绩与状态。

---

## 4. 关键 Hooks 说明

### 4.1 useMonitor.js
监考检测组合式函数：
- **事件监听**：监听切屏、复制粘贴、窗口失焦等事件
- **状态持久化**：监考事件写入本地/远端存储
- **断网恢复**：网络恢复后自动补发事件
- **异常补偿**：页面崩溃后重建会话状态

### 4.2 useAutoSave.js
答案自动保存：
- 答题过程中定时保存
- 题目切换时即时保存
- 网络异常时本地缓存，恢复后上传

## 5. 关键 Service 说明

### 5.1 exam_record_service.py
- 考试记录管理
- 监考行为分析（切屏次数、停留时长、风险等级）

### 5.2 grading_service.py
- 客观题自动判分
- 主观题评分调度（调用 AI 服务）
- 监考详情生成

### 5.3 exam_service.py
- 考试 CRUD：创建、发布、关闭、查询
- 考试状态机管理（draft → published → closed）

### 5.4 ai_scoring_service.py
- AI 评分服务客户端
- 封装 Backend → AI Service 的 HTTP 调用
- 超时、重试、降级处理
