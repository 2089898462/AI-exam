## 2. 服务划分表

| 服务名称 | 技术栈 | 端口 | 说明 |
|---------|--------|------|------|
| Frontend | Vue 3 + Vite | 5173 | 用户界面，支持候选人考试、HR 监考、管理员管理 |
| Backend | FastAPI | 8000 | 业务中台，负责权限、考试、评分、监考等核心逻辑 |
| AI Service | FastAPI + LLM SDK | 8001 | 独立 AI 服务，负责主观题评分、报告生成、对话交互 |
| MySQL | MySQL 8.0 | 3306 | 业务数据持久化存储 |

---

## 3. 通信方式

| 通信链路 | 协议 | 数据格式 | 说明 |
|---------|------|---------|------|
| Frontend ↔ Backend | REST API | JSON | 外部 HTTP 调用，JWT 鉴权 |
| Backend ↔ AI Service | HTTP | JSON | 内部服务调用，无公网暴露 |
| Backend ↔ MySQL | TCP | SQL | ORM（SQLAlchemy 2.0）驱动 |
| AI Service ↔ LLM | HTTPS | JSON | 通过 SDK 调用 DeepSeek 等大模型 |

## 4. 部署架构

### 4.1 Docker Compose 支持
项目根目录提供 `docker-compose.yml`，一键启动全套服务：

- **frontend**：基于 `node:18-alpine` 镜像，构建静态资源并通过 Nginx 托管
- **backend**：基于 `python:3.11-slim` 镜像，uvicorn 启动
- **ai-service**：独立 Python 容器
- **mysql**：官方 MySQL 8.0 镜像，挂载数据卷

### 4.2 开发环境
开发阶段支持本地运行：

```
本地开发模式：
├── Frontend   → npm run dev     (5173)
├── Backend    → uvicorn app.main:app --reload (8000)
├── AI Service → uvicorn app.main:app --reload (8001)
└── MySQL      → 本地或 Docker 运行 (3306)
```

## 5. 技术栈总览

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **前端** | Vue 3、Vite、Element Plus、Pinia、Vue Router、Axios | 渐进式框架 + 组件化 UI + 状态管理 |
| **后端** | FastAPI、SQLAlchemy 2.0、Alembic、Pydantic | 异步 Web 框架 + ORM + 数据校验 |
| **AI 服务** | FastAPI、DeepSeek API、OpenAI SDK | Agent 架构 + 多模型适配 |
| **数据库** | MySQL 8.0、InnoDB、utf8mb4 | 事务引擎 + 完整 Unicode 支持 |

## 6. 架构设计原则

1. **前后端分离**：前端仅通过 REST API 与后端交互，便于独立迭代与部署。
2. **AI 服务独立**：AI 相关能力通过独立服务暴露，避免业务系统与大模型强耦合。
3. **分层解耦**：后端严格遵循 API → Schema → Service → Model 分层。
4. **面向接口**：服务之间通过明确的 HTTP/REST 契约通信，便于维护与测试。
5. **安全优先**：内部服务调用不走公网，敏感数据按需脱敏后再交给 AI 服务。
