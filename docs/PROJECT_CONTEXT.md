# 1. 项目名称

**企业AI智能考试与能力评估系统**

---

# 2. 项目目标

## 核心目标
构建一个企业内部招聘考试 + 试用期考试平台，通过 AI 能力提升考试管理效率和评估质量。

## 业务价值
- 替代人工批改，效率提升 80%+
- AI 主观题评分，标准统一
- 个性化 AI 能力分析报告，帮助员工成长

## 使用场景
1. 招聘面试阶段纸面考试替代
2. 员工试用期培训考试
3. 员工学习成果评估

## 目标用户
- **HR 管理员**：后台创建考试、导入题目、查看成绩
- **候选人/员工**：手机端参加考试、查看结果和 AI 报告

---

# 3. 核心设计

## 设计原则

### 1. 固定试卷模式
- MVP 采用固定试卷模式
- 由 HR 手动创建考试并导入题目
- 第一版不开发自动组卷功能

### 2. 候选人无需注册账号
- 候选人不是系统用户
- 采用嵌入式身份信息（candidate_name / candidate_phone / candidate_email）
- 无需 candidate_user 表

### 3. HR 拥有后台管理权限
- HR 通过用户名密码登录后台
- 权限保护：所有 HR 端点必须鉴权
- 数据隔离：HR 只能操作自己创建的考试

### 4. AI 能力后置接入
- AI 服务独立部署（端口 8001）
- Backend 通过 HTTP 调用 AI-Service
- 解耦业务逻辑与 AI 能力，支持独立扩缩容

### 5. 当前重点：完成考试业务闭环
- 优先实现考试流程完整可用
- 从候选人进入 → 答题 → 提交 → 查看成绩
- AI 评分和报告在业务流程稳定后接入

## 技术决策（已确定）

| # | 决策 | 说明 |
|---|------|------|
| 1 | MVP 固定试卷模式 | 自动组卷复杂度高，首期聚焦核心流程 |
| 2 | 候选人嵌入式身份 | 无需注册账号，降低使用门槛 |
| 3 | AI 服务独立部署 | 解耦业务与 AI，独立扩缩容 |
| 4 | Prompt 与代码分离 | YAML 版本化管理，便于迭代 |
| 5 | Alembic 管理数据库 | 版本化迁移，支持回滚 |
| 6 | 密码 bcrypt 哈希 | 安全行业标准，防止明文存储 |
| 7 | API 统一 /api/v1 前缀 | 支持未来版本扩展 |
| 8 | Service 层封装业务逻辑 | API 不直接操作数据库 |

# 4. 技术架构

## 整体架构图

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│    Frontend     │────▶│    Backend      │────▶│    MySQL 8      │
│  Vue3 + Vite    │     │  FastAPI        │     │                 │
│  Element Plus   │◀────│  SQLAlchemy     │◀────│                 │
└─────────────────┘     └────────┬────────┘     └─────────────────┘
                                 │ HTTP
                                 ▼
                        ┌─────────────────┐
                        │   AI Service    │
                        │  FastAPI        │
                        │  OpenAI SDK     │
                        └─────────────────┘
```

## 服务划分

| 服务 | 端口 | 技术栈 | 职责 |
|------|------|--------|------|
| Frontend | 3000 | Vue3 + Vite + Element Plus | 用户界面，HR 后台 + 候选人考试页 |
| Backend | 8000 | FastAPI + SQLAlchemy | 业务 API，考试 CRUD、评分逻辑 |
| AI Service | 8001 | FastAPI + OpenAI SDK | AI 评分、AI 报告生成 |
| MySQL | 3306 | MySQL 8.0 | 数据存储 |
