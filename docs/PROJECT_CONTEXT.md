# 1. 项目名称

**AI考试系统（企业内部版）**

---

# 2. 项目目标

## 核心目标
构建一个企业内部 AI 智能考试与测评系统，为人事部门提供一站式考试管理解决方案。

## 功能范围
- 考试创建
- 考试发布
- 员工在线考试
- 自动评分（客观题）
- AI 主观题评分
- AI 考试分析报告
- HR 成绩管理

## 业务价值
- 替代人工批改，效率提升 80%+
- AI 主观题评分，标准统一
- AI 考试分析报告，帮助 HR 快速了解考试情况
- 员工学习成果可视化

## 业务场景
1. 新人入职考试
2. 安全培训考试
3. 岗位技能考试
4. 员工学习成果评估

## 目标用户
- **管理员**：系统维护、用户管理
- **HR（核心角色）**：创建考试、发布考试、查看成绩、查看 AI 报告
- **员工**：参加考试、查看个人成绩

# 3. 核心设计

## 设计原则

### 1. 固定试卷模式
- 采用固定试卷模式
- 由 HR 手动创建考试并导入题目
- 不开发随机组卷功能

### 2. 员工考试模式
- 员工通过姓名+手机验证身份参加考试
- 采用嵌入式身份信息（candidate_name / candidate_phone / candidate_email）
- 考试记录与用户解耦

### 3. HR 统一管理
- 考试统一由人事部门管理
- HR 通过用户名密码登录后台
- 所有 HR 端点必须鉴权

### 4. AI 能力后置接入
- AI 服务独立部署（端口 8001）
- Backend 通过 HTTP 调用 AI-Service
- 解耦业务逻辑与 AI 能力，支持独立扩缩容

### 5. 聚焦核心流程
- 优先实现考试流程完整可用
- 从员工进入 → 答题 → 提交 → 查看成绩
- AI 评分和报告在业务流程稳定后接入

## 技术决策（已确定）

| # | 决策 | 说明 |
|---|------|------|
| 1 | 固定试卷模式 | 首期聚焦核心流程，不开发随机组卷 |
| 2 | 员工嵌入式身份 | 无需注册账号，降低使用门槛 |
| 3 | AI 服务独立部署 | 解耦业务与 AI，独立扩缩容 |
| 4 | Prompt 与代码分离 | YAML 版本化管理，便于迭代 |
| 5 | Alembic 管理数据库 | 版本化迁移，支持回滚 |
| 6 | 密码 bcrypt 哈希 | 安全行业标准，防止明文存储 |
| 7 | API 统一 /api/v1 前缀 | 支持未来版本扩展 |
| 8 | Service 层封装业务逻辑 | API 不直接操作数据库 |

# 4. 技术架构

## 整体架构图

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│    Frontend     │────▶│    Backend      │────▶│    MySQL 8      │
│  Vue3 + Vite    │     │  FastAPI        │     │                 │
│  Element Plus   │◀────│  SQLAlchemy     │◀────│                 │
└─────────────────┘     └────────┬────────┘     └─────────────────┘
                                 │ HTTP
                                 ▼
                        ┌─────────────────┐
                        │   AI Service    │
                        │  FastAPI        │
                        │  OpenAI SDK     │
                        └─────────────────┘
```

## 服务划分

| 服务 | 端口 | 技术栈 | 职责 |
|------|------|--------|------|
| Frontend | 3000 | Vue3 + Vite + Element Plus | 用户界面，HR 后台 + 员工考试页 |
| Backend | 8000 | FastAPI + SQLAlchemy | 业务 API，考试 CRUD、评分逻辑 |
| AI Service | 8001 | FastAPI + OpenAI SDK | AI 评分、AI 报告生成 |
| MySQL | 3306 | MySQL 8.0 | 数据存储 |
