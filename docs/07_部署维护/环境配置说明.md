# 环境配置说明

## 后端环境变量（`backend/.env`）

```env
# 数据库连接
DATABASE_URL=mysql+aiomysql://user:password@localhost:3306/ai_exam

# JWT 配置
SECRET_KEY=请替换为随机生成的密钥字符串
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=1440

# CORS 配置
CORS_ORIGINS=http://localhost:5173
```

> ⚠️ **重要**：`SECRET_KEY` 必须修改为随机字符串，切勿使用默认值或提交到版本库。

## AI 服务环境变量（`ai-service/.env`）

```env
# （必填）DeepSeek API 密钥
DEEPSEEK_API_KEY=你的API密钥

# DeepSeek 接口地址
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1

# 使用的模型名称
MODEL_NAME=deepseek-chat

# AI 评分超时时间（秒）
SCORE_TIMEOUT=30
```

## 数据库配置

| 配置项 | 推荐值 |
|--------|--------|
| MySQL 版本 | 8.0+ |
| 字符集 | utf8mb4 |
| 存储引擎 | InnoDB |
| 排序规则 | utf8mb4_unicode_ci |

### 创建数据库

```sql
CREATE DATABASE ai_exam
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

## 端口分配

| 服务 | 开发端口 | 生产端口 |
|------|----------|----------|
| Backend（后端 API） | 8000 | 8000 |
| AI Service（AI 评分） | 8001 | 8001 |
| Frontend（前端页面） | 5173 | 3000 |

> 如端口冲突，需同步修改各服务的启动配置与 `.env` 中的 CORS 设置。

## 防火墙配置

确保以下端口允许入站连接：

- `8000` — 后端 API
- `8001` — AI 评分服务
- `5173` — 前端开发服务器
- `3000` — 前端生产（Nginx / 托管服务）

### Windows 防火墙示例

```powershell
# 以管理员身份运行
netsh advfirewall firewall add rule name="AI Exam Backend" dir=in action=allow protocol=TCP localport=8000
netsh advfirewall firewall add rule name="AI Exam AI-Service" dir=in action=allow protocol=TCP localport=8001
netsh advfirewall firewall add rule name="AI Exam Frontend" dir=in action=allow protocol=TCP localport=5173
```
