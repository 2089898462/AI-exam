# 本地运行说明

## 环境要求

| 组件 | 最低版本 | 推荐版本 |
|------|----------|----------|
| 操作系统 | Windows 10 | Windows 11 |
| Python | 3.10 | 3.10+ |
| Node.js | 18 | 18 LTS |
| MySQL | 8.0 | 8.0+ |

## 快速启动（推荐）

一键启动脚本已封装好全部初始化步骤：

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd AI考试系统
   ```

2. **配置数据库**
   详见「环境配置说明.md」，确保 MySQL 服务已启动且数据库已创建。

3. **双击 `start-system.bat`**
   脚本将自动完成：安装依赖、启动后端、启动 AI 服务、启动前端。

4. **访问系统**
   打开浏览器访问 <http://localhost:3000>

## 手动启动

如需分别控制各服务，可按以下步骤操作：

### 1. 启动后端服务

```bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 启动 AI 服务

```bash
cd ai-service
python -m uvicorn main:app --host 0.0.0.0 --port 8001 --reload
```

### 3. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

## 访问地址

| 服务 | 开发环境地址 |
|------|-------------|
| Backend（后端 API） | <http://localhost:8000> |
| AI Service（AI 评分服务） | <http://localhost:8001> |
| Frontend（前端页面） | <http://localhost:5173> |

## 初始化配置

首次运行后，请访问 <http://localhost:8000/docs> 打开 Swagger 文档页面，使用接口创建默认管理员账号。

> 生产环境部署时，前端通过 `npm run build` 构建后由 `start-system.bat` 统一托管在端口 3000。
