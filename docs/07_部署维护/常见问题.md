# 常见问题排查

## Q1：端口被占用怎么办？

**症状**：启动服务时报 `Address already in use` 或端口绑定失败。

**解决方法**：
1. 修改对应服务的端口配置（参见「环境配置说明」）
2. 或使用以下命令找到占用进程并终止：
   ```bash
   netstat -ano | findstr :8000
   taskkill /PID <进程ID> /F
   ```

---

## Q2：CORS 错误怎么办？

**症状**：浏览器控制台报 `CORS policy` 相关错误。

**解决方法**：
1. 检查后端 `backend/.env` 中的 `CORS_ORIGINS` 配置
2. 确保前端实际访问地址在白名单中：
   ```env
   CORS_ORIGINS=http://localhost:5173,http://localhost:3000
   ```
3. 多地址用逗号分隔

---

## Q3：前端页面空白怎么办？

**症状**：访问前端地址后页面无内容。

**解决方法**：
1. 检查 Vite 开发服务器是否正在运行
2. 打开浏览器开发者工具，查看 Console 面板的错误信息
3. 确认后端 API 服务是否正常（访问 <http://localhost:8000/docs>）
4. 尝试清除浏览器缓存后刷新

---

## Q4：AI 评分超时怎么办？

**症状**：评分阶段长时间等待或报超时错误。

**解决方法**：
1. 检查 `ai-service/.env` 中的 `DEEPSEEK_API_KEY` 是否正确配置
2. 确认网络连接正常，可访问 `https://api.deepseek.com`
3. 调大 `SCORE_TIMEOUT` 参数（默认 30 秒）
4. 查看 AI 服务日志确认是否为模型侧问题

---

## Q5：数据库连接失败怎么办？

**症状**：后端启动时报 `Can't connect to MySQL server`。

**解决方法**：
1. 确认 MySQL 服务已启动
2. 检查 `backend/.env` 中的 `DATABASE_URL` 配置
3. 确认数据库 `ai_exam` 已创建
4. 验证用户名密码是否正确：
   ```bash
   mysql -u user -p -e "SELECT 1"
   ```

---

## Q6：移动端无法访问怎么办？

**症状**：同局域网手机无法访问本机前端。

**解决方法**：
1. 确认前端已绑定 `0.0.0.0`（`npm run dev` 默认绑定）
2. 检查 `CORS_ORIGINS` 是否已包含手机 IP 或使用通配符
3. 确认手机与电脑在同一局域网
4. 临时关闭 Windows 防火墙测试

---

## Q7：考试提交失败怎么办？

**症状**：候选人提交答卷时报错误。

**解决方法**：
1. 检查网络连接是否稳定
2. 查看后端服务日志（`backend/logs/` 或控制台输出）
3. 确认 AI 评分服务是否正常运行
4. 检查数据库连接状态

---

## Q8：监考数据丢失怎么办？

**症状**：HR 监考详情页面显示事件为空或不完整。

**解决方法**：
1. 确认候选人是「提交成功」而非直接关闭页面
2. 检查候选人浏览器 `sessionStorage` 是否被意外清除
3. 候选人可重新进入考试（监考数据会从后端恢复）
4. 刷新 HR 监考详情页面重试

---

## Q9：如何重置管理员密码？

**解决方法**：直接修改 `user` 表的 `password_hash` 字段。

1. 生成新的 bcrypt 哈希值：
   ```python
   python -c "import bcrypt; print(bcrypt.hashpw(b'NewPassword123', bcrypt.gensalt()).decode())"
   ```
2. 在 MySQL 中执行更新：
   ```sql
   UPDATE user SET password_hash = '新生成的哈希值' WHERE username = 'admin';
   ```

---

## Q10：如何添加新管理员？

**方法一：通过注册接口**
访问 <http://localhost:8000/docs>，调用 `/api/auth/register` 接口创建新账号，并手动在数据库中将其角色改为 `admin`。

**方法二：直接 SQL 插入**
```sql
INSERT INTO user (username, email, password_hash, role, created_at)
VALUES ('newadmin', 'admin@example.com', 'bcrypt哈希值', 'admin', NOW());
```
