# 数据备份与恢复

## 数据库备份

### 全量备份

```bash
# MySQL 全量备份
mysqldump -u root -p ai_exam > backup_20260821.sql
```

### 仅结构备份

```bash
# 仅导出表结构（不含数据）
mysqldump -u root -p --no-data ai_exam > schema_backup.sql
```

### 仅数据备份

```bash
# 仅导出数据（不含建表语句）
mysqldump -u root -p --no-create-info ai_exam > data_backup.sql
```

## 数据库恢复

```bash
# 恢复指定备份文件
mysql -u root -p ai_exam < backup_20260821.sql
```

> ⚠️ 恢复操作将覆盖现有数据，务必先执行备份。

## Alembic 数据库迁移

### 升级到最新版本

```bash
cd backend
set PYTHONPATH=.
alembic upgrade head
```

### 降级一个版本

```bash
alembic downgrade -1
```

### 查看当前版本

```bash
alembic current
```

### 查看迁移历史

```bash
alembic history
```

### 创建新迁移脚本

```bash
alembic revision --autogenerate -m "描述本次变更"
```

## 备份策略建议

| 策略 | 说明 |
|------|------|
| 备份频率 | 每日全量备份 |
| 保留周期 | 最近 30 天 |
| 存储位置 | 本地 + 异地（如对象存储） |
| 校验机制 | 定期恢复演练（建议每月一次） |

### Windows 定时备份（可选）

创建 `backup.bat` 并通过「任务计划程序」每日执行：

```batch
@echo off
set BACKUP_DIR=D:\backups
set TIMESTAMP=%date:~0,4%%date:~5,2%%date:~8,2%
mysqldump -u root -pYourPassword ai_exam > %BACKUP_DIR%\ai_exam_%TIMESTAMP%.sql
forfiles /p %BACKUP_DIR% /m *.sql /d -30 /c "cmd /c del @path"
```

## 监考数据清理

- 候选人提交成功后，`sessionStorage` 中的监考数据自动清除
- 如遇提交失败，监考数据将保留在本地供重试
- 极端情况下需手动清理，可在浏览器控制台执行：
  ```javascript
  sessionStorage.clear();
  ```
