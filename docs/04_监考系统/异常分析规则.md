# 异常分析规则

## 一、风险等级定义

监考系统通过对考生的行为事件进行自动分析，计算出四个风险等级，供 HR 端审核参考。

### 1.1 等级划分

| 等级 | 标识 | 颜色标识 | 定义 | 判定标准 |
|------|------|----------|------|----------|
| 正常 | `normal` | 🟢 绿色 | 无异常行为 | `leave_count = 0` |
| 轻度 | `low` | 🟡 黄色 | 轻度异常 | `leave_count` 1–2 次，无长时间离开 |
| 中度 | `medium` | 🟠 橙色 | 中度异常 | `leave_count ≥ 3` 次 或 单次离开 ≥ 60 秒 |
| 高度 | `high` | 🔴 红色 | 高度异常 | `leave_count ≥ 5` 次 或 单次离开 ≥ 5 分钟 或 高频快速往返 |

### 1.2 等级判定逻辑

```python
def determine_risk_level(leave_count, max_duration_ms, rapid_trips, leave_density):
    # high 条件（满足任一）
    if leave_count >= 5:
        return 'high'
    if max_duration_ms >= 5 * 60 * 1000:  # 5 分钟
        return 'high'
    if rapid_trips >= 5:                   # 高频快速往返
        return 'high'

    # medium 条件（满足任一）
    if leave_count >= 3:
        return 'medium'
    if max_duration_ms >= 60 * 1000:       # 60 秒
        return 'medium'
    if leave_density > 0.6:                # 5 分钟内 >3 次（密度 >0.6 次/分钟）
        return 'medium'

    # low 条件
    if leave_count >= 1:
        return 'low'

    # normal
    return 'normal'
```

## 二、分析规则详解

### 规则 1：快速往返检测 `_count_rapid_trips`

**检测目标：** 识别短时间内高频的 leave → return 行为，这类行为往往是切屏查看答案后立即返回。

**检测逻辑：**

```
输入：事件列表 events
遍历所有事件对 (leave, return)
    │
    ├── leave.type === 'exam_leave' 或 'leave_recovered'
    ├── return.type === 'exam_return'
    └── return.timestamp - leave.timestamp ≤ 5000ms（5 秒）
        │
        ├── 是 → return 标记 tag: 'rapid_leave_return'
        └── 否 → 不标记
    │
    ▼
输出：rapid_trips 计数
```

**伪代码：**

```python
def _count_rapid_trips(events):
    rapid_count = 0
    sorted_events = sorted(events, key=lambda e: e['timestamp'])

    for i, event in enumerate(sorted_events):
        if event['type'] in ('exam_leave', 'leave_recovered'):
            # 查找最近的 return 事件
            for j in range(i + 1, len(sorted_events)):
                if sorted_events[j]['type'] == 'exam_return':
                    duration = sorted_events[j]['timestamp'] - event['timestamp']
                    if duration <= 5000:  # ≤ 5 秒
                        rapid_count += 1
                        # 标记 return 事件
                        if 'rapid_leave_return' not in sorted_events[j].get('tags', []):
                            sorted_events[j].setdefault('tags', []).append('rapid_leave_return')
                    break  # 只看最近的一个 return

    return rapid_count
```

**风险标签：**
- 标记 `rapid_leave_return`
- 累计 rapid_trips 数量用于判定 high 风险

### 规则 2：长时间离开检测 `_calculate_max_single_duration`

**检测目标：** 识别单次离开时间过长的行为，长时间离开可能意味着使用其他设备或查阅资料。

**检测逻辑：**

```
输入：事件列表 events
遍历所有 leave 事件（exam_leave + leave_recovered）
    │
    ├── exam_leave：
    │   duration = 对应 return.timestamp - leave.timestamp
    │
    ├── leave_recovered：
    │   duration = recovered.endTime - recovered.timestamp
    │   （直接使用事件中已计算的 duration）
    │
    └── duration ≥ 60000ms（60 秒）
        │
        ├── 是 → return 标记 tag: 'long_leave'
        └── 否 → 不标记
    │
    ▼
输出：max_duration_ms（最长离开时长）
```

**关键点：**
- `exam_leave` 事件的 duration 由对应的 `exam_return` 计算得出
- `leave_recovered` 事件的 duration 在生成时已计算
- **两种 leave 事件均纳入计算范围**
- 标记 `long_leave` tag

**伪代码：**

```python
def _calculate_max_single_duration(events):
    max_duration = 0
    sorted_events = sorted(events, key=lambda e: e['timestamp'])

    for i, event in enumerate(sorted_events):
        if event['type'] == 'exam_leave':
            # 查找对应的 return 事件
            for j in range(i + 1, len(sorted_events)):
                if sorted_events[j]['type'] == 'exam_return':
                    duration = sorted_events[j]['timestamp'] - event['timestamp']
                    if duration > max_duration:
                        max_duration = duration
                    if duration >= 60000:
                        tags = sorted_events[j].setdefault('tags', [])
                        if 'long_leave' not in tags:
                            tags.append('long_leave')
                    break

        elif event['type'] == 'leave_recovered':
            duration = event.get('duration', 0)
            if duration > max_duration:
                max_duration = duration
            if duration >= 60000:
                tags = event.setdefault('tags', [])
                if 'long_leave' not in tags:
                    tags.append('long_leave')

    return max_duration
```

### 规则 3：高频离开检测 `_calc_max_leave_density`

**检测目标：** 识别短时间内高密度的离开行为，高频离开可能对应多次切屏查阅。

**检测逻辑：**

```
输入：事件列表 events
计算滚动窗口内的离开密度
    │
    ├── 时间窗口：300 秒（5 分钟）
    ├── 密度 = 窗口内 leave 次数 / 5（次/分钟）
    └── 密度 > 0.6 次/分钟
        │
        ├── 是 → 标记 tag: 'frequent_leave'
        └── 否 → 不标记
    │
    ▼
输出：max_density（最大离开密度）
```

**伪代码：**

```python
def _calc_max_leave_density(events):
    max_density = 0.0
    window_seconds = 300  # 5 分钟窗口

    # 收集所有 leave 事件的时间戳
    leave_timestamps = []
    for event in events:
        if event['type'] in ('exam_leave', 'leave_recovered'):
            leave_timestamps.append(event['timestamp'])

    if len(leave_timestamps) < 3:
        return 0.0  # 不足 3 次不计算密度

    leave_timestamps.sort()

    # 滑动窗口
    for i in range(len(leave_timestamps)):
        window_start = leave_timestamps[i]
        window_end = window_start + window_seconds * 1000

        # 计算窗口内的 leave 次数
        count = sum(
            1 for ts in leave_timestamps
            if window_start <= ts <= window_end
        )

        density = count / (window_seconds / 60)  # 次/分钟
        if density > max_density:
            max_density = density

        if density > 0.6:
            # 标记相关事件
            for event in events:
                if event['type'] in ('exam_leave', 'leave_recovered'):
                    tags = event.setdefault('tags', [])
                    if 'frequent_leave' not in tags:
                        tags.append('frequent_leave')

    return max_density
```

**密度参考：**

| 密度（次/分钟） | 5 分钟内 leave 次数 | 风险等级 |
|-----------------|---------------------|----------|
| 0.2             | 1 次                | normal   |
| 0.4             | 2 次                | low      |
| 0.6             | 3 次                | medium   |
| 1.0             | 5 次                | high     |

### 规则 4：网络关联检测 `_count_network_related_leaves`

**检测目标：** 识别与网络断开时间关联的 leave 事件，判断离开是否由网络问题导致。

**检测逻辑：**

```
输入：事件列表 events
遍历所有 leave 事件
    │
    ├── leave 事件时间戳
    ├── 查找最近的 network_offline 事件
    └── leave.timestamp - network_offline.timestamp ≤ 30000ms（30 秒）
        │
        ├── 是 → leave 标记 tag: 'network_related'
        │        （说明离开可能由网络导致，降低风险判定）
        └── 否 → 不标记
    │
    ▼
输出：network_related_count（网络关联的 leave 数量）
```

**伪代码：**

```python
def _count_network_related_leaves(events):
    related_count = 0

    # 提取所有 network_offline 事件的时间戳
    offline_timestamps = [
        e['timestamp'] for e in events
        if e['type'] == 'network_offline'
    ]

    if not offline_timestamps:
        return 0  # 无离线事件，无需检测

    for event in events:
        if event['type'] in ('exam_leave', 'leave_recovered'):
            leave_ts = event['timestamp']

            # 检查是否在某个 network_offline 后 30 秒内
            for offline_ts in offline_timestamps:
                if 0 <= (leave_ts - offline_ts) <= 30000:
                    related_count += 1
                    tags = event.setdefault('tags', [])
                    if 'network_related' not in tags:
                        tags.append('network_related')
                    break  # 只标记一次

    return related_count
```

**设计意义：**
- 如果 leave 发生在网络断开后短时间内，可能是网络问题导致的被动离开
- 此标记可降低 HR 审核时的疑虑
- 在风险等级计算中作为**减轻因素**

### 规则 5：刷新尝试检测

**检测目标：** 检测考生是否尝试通过刷新页面来重置考试状态。

**检测逻辑：**

```
输入：事件列表 events
查找 refresh_attempt 类型事件
    │
    ├── 存在 refresh_attempt 事件
    │   → 标记 tag: 'refresh_attempt'
    │   → 记录 source（如 bfcache）
    │
    └── 不存在 → 无标记
    │
    ▼
输出：has_refresh_attempt（布尔值）
```

**伪代码：**

```python
def _detect_refresh_attempt(events):
    for event in events:
        if event['type'] == 'refresh_attempt':
            return True, event.get('source', 'unknown')
    return False, None
```

## 四、审核建议生成

### 4.1 按风险等级生成

| 风险等级 | 审核建议 | 视觉呈现 |
|----------|----------|----------|
| **normal** | 无明显异常行为，建议正常评分 | 🟢 绿色徽章 + "正常"标签 |
| **low** | 存在轻度异常行为，建议查看异常时间段答题情况 | 🟡 黄色徽章 + "轻度异常"标签 |
| **medium** | 存在中度异常行为，建议人工复核离开期间的答题内容 | 🟠 橙色徽章 + "中度异常"标签 |
| **high** | 存在高度异常行为，建议重点复核全部答题内容 | 🔴 红色徽章 + "高度异常"标签 |

### 4.2 带行为标签的建议

当存在特定行为标签时，审核建议会附加更具体的指引。

**normal 等级：**
```
无明显异常行为，建议正常评分。
```

**low 等级示例：**
```
存在轻度异常行为：离开页面 2 次，最长离开 15 秒。
建议查看异常时间段的答题情况，确认答题连贯性。
```

**medium 等级示例：**
```
存在中度异常行为：离开页面 4 次，最长离开 135 秒。
检测到：快速往返 2 次、长时间离开 1 次。
建议人工复核离开期间的答题内容，重点关注答案的异常变化。
```

**high 等级示例：**
```
存在高度异常行为：离开页面 7 次，最长离开 320 秒。
检测到：快速往返 5 次、长时间离开 2 次、高频离开（密度 1.2 次/分钟）。
建议重点复核全部答题内容，必要时联系考生进行调查。
```

### 4.3 动态建议生成逻辑

```python
def generate_review_suggestion(risk_level, behavior_tags, analysis_data):
    suggestions = []

    # 基础建议
    base = {
        'normal': '无明显异常行为，建议正常评分。',
        'low': '存在轻度异常行为，建议查看异常时间段答题情况。',
        'medium': '存在中度异常行为，建议人工复核离开期间的答题内容。',
        'high': '存在高度异常行为，建议重点复核全部答题内容。'
    }

    # 附加说明
    if 'rapid_leave_return' in behavior_tags:
        suggestions.append(f"快速往返 {analysis_data['rapid_trips']} 次（≤5秒）")

    if 'long_leave' in behavior_tags:
        duration_min = analysis_data['max_duration_ms'] / 60000
        suggestions.append(f"最长离开 {duration_min:.1f} 分钟")

    if 'frequent_leave' in behavior_tags:
        suggestions.append(f"高频离开，密度 {analysis_data['max_density']:.1f} 次/分钟")

    if 'refresh_attempt' in behavior_tags:
        suggestions.append("存在页面刷新/恢复尝试")

    if 'network_related' in behavior_tags:
        suggestions.append("部分离开与网络断开时间关联")

    # 组合最终建议
    result = base[risk_level]
    if suggestions:
        result += "\n检测到：" + "、".join(suggestions) + "。"
        result += "\n建议：" + _get_action_by_level(risk_level)

    return result
```

## 五、后端关键函数说明

### 5.1 ExamRecordService.analyze_monitor_behavior(monitor_data)

**功能：** 监考分析的主入口函数，协调执行所有分析规则。

**输入参数：**
```python
monitor_data = {
    'events': [...],              # 完整事件列表
    'orientationEvents': [...],   # 方向变化事件
    'networkEvents': [...],       # 网络事件
    'stats': {
        'leaveCount': int,
        'totalDuration': int
    }
}
```

**返回结构：**
```python
{
    'risk_level': str,           # normal / low / medium / high
    'behavior_tags': list,       # 行为标签数组
    'risk_reasons': list,        # 风险原因数组
    'max_duration_ms': int,     # 最长离开时长
    'max_density': float,        # 最大离开密度
    'rapid_trips': int,          # 快速往返次数
    'leave_count': int,          # 离开总次数
    'network_related_count': int # 网络关联次数
}
```

**执行步骤：**
1. 合并所有事件到统一事件流
2. 调用 `_count_rapid_trips()` 检测快速往返
3. 调用 `_calculate_max_single_duration()` 检测最长离开
4. 调用 `_calc_max_leave_density()` 计算最大密度
5. 调用 `_count_network_related_leaves()` 检测网络关联
6. 调用 `_detect_refresh_attempt()` 检测刷新尝试
7. 汇总 behavior_tags 和 risk_reasons
8. 判定最终风险等级

### 5.2 ExamRecordService._count_rapid_trips(events)

**功能：** 统计 5 秒内 leave → return 的快速往返次数。

**参数：** `events` — 事件列表

**返回：** `int` — 快速往返次数

**标记副作用：** 为符合条件的 `exam_return` 事件添加 `rapid_leave_return` tag

### 5.3 ExamRecordService._calculate_max_single_duration(events)

**功能：** 计算单次离开的最大时长。

**参数：** `events` — 事件列表

**返回：** `int` — 最长离开时长（毫秒）

**标记副作用：** 为时长 ≥ 60 秒的 return 事件添加 `long_leave` tag

**注意事项：**
- 同时计算 `exam_leave` + `exam_return` 对
- 同时计算 `leave_recovered` 事件自身的 duration
- 两种 leave 事件均纳入统计

### 5.4 ExamRecordService._calc_max_leave_density(events)

**功能：** 计算 5 分钟滑动窗口内的最大离开密度。

**参数：** `events` — 事件列表

**返回：** `float` — 最大离开密度（次/分钟）

**标记副作用：** 为密度超标的 leave 事件添加 `frequent_leave` tag

### 5.5 ExamRecordService._count_network_related_leaves(events)

**功能：** 统计与网络断开关联的 leave 事件数量。

**参数：** `events` — 事件列表

**返回：** `int` — 网络关联的 leave 数量

**标记副作用：** 为网络关联的 leave 事件添加 `network_related` tag

## 六、风险等级快速判定参考表

| 条件 | 等级 | 审核建议 |
|------|------|----------|
| leave_count = 0 | normal | 正常评分 |
| leave_count 1–2，无 long_leave | low | 查看异常时间段答题 |
| leave_count ≥ 3 或 max_duration ≥ 60s | medium | 人工复核离开期间答题 |
| leave_count ≥ 5 或 max_duration ≥ 5min 或 rapid_trips ≥ 5 | high | 重点复核全部答题 |

**补充规则：**
- 存在 `refresh_attempt` 事件时，至少判定为 **low**
- 存在 `network_related` 标记时，风险等级可考虑**降级**一档（如 high → medium）
- 密度 > 0.6 次/分钟 直接判定为 **medium**
- 密度 > 1.0 次/分钟 直接判定为 **high**
