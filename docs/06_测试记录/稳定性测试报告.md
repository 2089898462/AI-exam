# 稳定性测试报告

## 测试范围

## 测试方法

### 后端风险分析单元测试

- **通过率：8 / 8（100%）**
- 使用 pytest 框架对风险分析核心逻辑进行单元测试
- 覆盖 leave / return / leave_recovered 等关键事件的 duration 计算

### 前端 Node 端到端逻辑测试

- **通过率：18 / 18（100%）**
- 基于真实源码打包运行，模拟浏览器端监考逻辑
- 覆盖从进入考试到提交的完整监考数据生命周期

### 后端服务健康检查

- 服务启动正常，端口监听正常
- 数据库连接池状态稳定
- AI 服务调用超时处理正常
