# 功能测试报告

- 考试管理

## 测试方法

- **黑盒测试**：以管理员 / HR / 候选人三种角色进行全流程端到端测试
- **API 接口测试**：对后端 REST API 进行功能验证
- **前端页面测试**：验证页面交互、渲染与数据绑定正确性

## 已知限制

以下边缘场景未在本轮测试覆盖范围内：

- 网络极端波动下的答题数据同步
- 高并发（>50 人同时考试）的性能表现
- 极端浏览器环境（旧版 IE、小众浏览器）
- 候选人在考试中进行异常操作（如开发者工具修改请求）
