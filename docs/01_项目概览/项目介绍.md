# 项目介绍

## 项目名称

**AI考试系统（企业内部版）**

## 项目目标

构建企业内部 AI 智能考试与测评系统，替代人工批改。

## 业务价值

- **效率提升 80%+**：大幅降低 HR 与培训部门的阅卷工作量
- **AI 主观题评分标准统一**：消除不同阅卷人之间的主观偏差，评分结果稳定可复现
- **AI 分析报告辅助 HR 决策**：自动生成学员能力画像与知识点掌握分析，为招聘、晋升、培训提供数据支撑
- **员工学习成果可视化**：通过报告与趋势图直观呈现员工成长轨迹

## 业务场景

| 场景 | 说明 |
|------|------|
| 新人入职考试 | 入职时的基础能力与岗位知识测评 |
| 安全培训考试 | 生产安全、合规等必修培训后的考核 |
| 岗位技能考试 | 岗位晋升、技能认证的专项测评 |
| 员工学习成果评估 | 定期学习项目的成果验收与复盘 |

## 技术定位

- **前端**：Vue 3
- **后端**：FastAPI（Python）
- **AI 能力**：DeepSeek AI 大模型

系统采用经典的前后端分离架构，AI 评分与报告能力以独立服务形式部署，便于后续模型迭代与能力扩展。
